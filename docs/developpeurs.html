Guide technique de la chaîne

Comment tranchee3d trouve les câbles dans un nuage de points

Ce guide suit les données d'un bout à l'autre de la chaîne. Pour chaque étape : ce qu'elle reçoit, ce qu'elle produit, la fonction Python qui la fait, l'algorithme ou le modèle utilisé, les paramètres de config.py qui la règlent, et le code source exact. Principe général : détecter en 2D sur une ortho, mesurer en 3D sur le nuage. Un seul modèle appris (un U-Net) intervient, à l'étape de segmentation ; tout le reste est de la géométrie déterministe.

Trois règles qui traversent tout le code

  • Repère local. À la lecture, on soustrait origine = floor(min(xyz)). En Lambert 93, Y vaut environ 6 688 526 m : en float32 il ne reste que 0,5 m de précision. Tous les calculs se font en coordonnées locales, l'origine est rajoutée à l'export.
  • Une seule grille raster. Ortho, hauteur, tranchée, étiquettes et prédiction partagent la même grille (Rasters.x0, y1, pixel). xy_vers_px et px_vers_xy font le passage nuage ↔ pixels.
  • Tous les seuils sont dans Config. Aucune constante en dur dans les modules ; un TOML (--config) les surcharge, et une clé inconnue est refusée pour éviter les fautes de frappe.

@classmethod
def charger(cls, chemin: str | Path | None) -> "Config":
    """Config par défaut, ou surchargée par le TOML (clés inconnues refusées : protège des fautes de frappe)."""
    if chemin is None:
        return cls()
    donnees = tomllib.loads(Path(chemin).read_text(encoding="utf-8"))
    connus = {f.name for f in fields(cls)}
    inconnus = set(donnees) - connus
    if inconnus:
        raise ValueError(f"Paramètres inconnus dans {chemin} : {sorted(inconnus)}")
    return cls(**donnees)

02Lecture du nuage

nuage.lire_nuage renvoie un objet Nuage : coordonnées locales en float64, couleurs en uint8, origine et CRS.

Entréefichier LAS / LAZ colorisé

def lire_nuage(chemin) -> Nuage:
    las = laspy.read(str(chemin))
    xyz = np.column_stack([las.x, las.y, las.z]).astype(np.float64)
    origine = np.floor(xyz.min(axis=0))
    xyz -= origine
    try:
        rvb = np.column_stack([las.red, las.green, las.blue]).astype(np.float64)
    except AttributeError as e:
        raise ValueError("Le nuage n'a pas de couleurs RVB.") from e
    if rvb.max() > 255:           # couleurs codées sur 16 bits
        rvb /= 257.0
    crs = None
    try:
        c = las.header.parse_crs()
        crs = c.to_string() if c is not None else None
    except Exception:
        pass
    return Nuage(xyz, rvb.round().clip(0, 255).astype(np.uint8), origine, crs)

03Ortho RVB et raster de hauteur

Le modèle travaille sur une image. On projette le nuage verticalement sur une grille de pixel = 4 mm : dans chaque pixel, le point le plus haut l'emporte. On obtient une ortho RVB et, sur la même grille, un raster de hauteur.

EntréeNuage
SortieRasters(rvb (H,W,3) uint8, hauteur (H,W) float32 NaN si vide, x0, y1, pixel)
Méthodeprojection tri par Z + affectation NumPy ; trous par transformée de distance
Paramètrespixel 0,004 m · bouchage_px 3

L'astuce de vectorisation

Pas de boucle sur les points : on trie les indices par Z croissant, puis on écrit hauteur[pixel] = z dans cet ordre. Quand un indice de pixel est répété, NumPy garde la dernière affectation, donc le point le plus haut. Le tri est stable pour que le résultat soit reproductible.

ordre = np.argsort(nuage.xyz[:, 2], kind="stable")       # du plus bas au plus haut

r.rvb.reshape(-1, 3)[plat] = nuage.rvb[ordre]

Si une ortho fournie existe (<chantier>/ortho/*.tif), appliquer_ortho_fournie la rééchantillonne (rasterio reproject, bilinéaire) sur la même grille et remplace les couleurs là où elle couvre. La hauteur vient toujours du nuage.

generer_rasters ortho.py
def generer_rasters(nuage: Nuage, cfg: Config) -> Rasters:
    """Projection verticale : le point le plus haut de chaque pixel l'emporte."""
    p = cfg.pixel
    x0, y0 = nuage.xyz[:, :2].min(axis=0)
    x1, y1 = nuage.xyz[:, :2].max(axis=0)
    W = int(np.ceil((x1 - x0) / p)) + 1
    H = int(np.ceil((y1 - y0) / p)) + 1
    # bord haut = y0 + (H-1)p, pas y0 + Hp : sinon la ligne 0 est toujours vide et y0 tombe hors grille (ligne H)
    r = Rasters(np.zeros((H, W, 3), np.uint8), np.full((H, W), np.nan, np.float32), x0, y0 + (H - 1) * p, p)

    lig, col = r.xy_vers_px(nuage.xyz[:, 0], nuage.xyz[:, 1])
    lig, col = lig.clip(0, H - 1), col.clip(0, W - 1)      # points posés pile sur le bord
    ordre = np.argsort(nuage.xyz[:, 2], kind="stable")       # du plus bas au plus haut
    plat = (lig * W + col)[ordre]
    # en cas d'indices répétés, la dernière affectation (la plus haute) est conservée
    r.hauteur.reshape(-1)[plat] = nuage.xyz[ordre, 2]
    r.rvb.reshape(-1, 3)[plat] = nuage.rvb[ordre]

    _boucher(r, cfg.bouchage_px)
    return r
_boucher ortho.py
def _boucher(r: Rasters, dist_max: int) -> None:
    """Comble les petits trous par le plus proche voisin."""
    vide = np.isnan(r.hauteur)
    if dist_max <= 0 or not vide.any():
        return
    dist, (il, ic) = ndi.distance_transform_edt(vide, return_indices=True)
    a_combler = vide & (dist <= dist_max)
    r.hauteur[a_combler] = r.hauteur[il[a_combler], ic[a_combler]]
    r.rvb[a_combler] = r.rvb[il[a_combler], ic[a_combler]]
appliquer_ortho_fournie ortho.py
def appliquer_ortho_fournie(r: Rasters, chemin_ortho, origine) -> None:
    """Remplace les couleurs par celles d'une ortho GeoTIFF, rééchantillonnée sur la grille."""
    import rasterio
    from rasterio.warp import Resampling, reproject

    H, W = r.forme
    with rasterio.open(chemin_ortho) as src:
        dst = np.zeros((3, H, W), np.uint8)
        for b in range(3):
            reproject(
                rasterio.band(src, b + 1), dst[b],
                src_transform=src.transform, src_crs=src.crs,
                dst_transform=r.affine_monde(origine), dst_crs=src.crs,
                resampling=Resampling.bilinear,
            )
    couvert = dst.any(axis=0)
    r.rvb[couvert] = np.moveaxis(dst, 0, -1)[couvert]
    r.source_ortho = "fournie"

04Détection de la tranchée

Sans apprentissage : on estime le niveau du sol environnant, et la tranchée est ce qui est nettement en dessous. Cela donne la zone d'intérêt (où l'on cherche les objets) et la hauteur relative (4e canal du modèle).

EntréeRasters (hauteur)
SortieTranchee(zone, fond, hauteur_relative) à pleine résolution
Méthodemorphologie scipy.ndimage : centile glissant, ouverture, composantes connexes, dilatation
Paramètresgrille_sol 5 cm · fenetre_sol 2 m · centile_sol 60 · profondeur_min 15 cm · surface_min_tranchee 0,5 m² · marge_tranchee 60 cm
  1. Basse résolution. La hauteur est réduite par médiane de blocs f × f, avec f = round(grille_sol / pixel) = 12 px (4,8 cm). Les blocs vides sont remplis par leur plus proche voisin (distance_transform_edt).
  2. Sol. percentile_filter au 60e centile sur une fenêtre de fenetre_sol (43 cellules ≈ 2 m), puis flou gaussien. La fenêtre doit faire plus de deux fois la largeur de la tranchée : le centile ne « voit » alors que le terrain naturel.
  3. Fond de tranchée. sol − hauteur > profondeur_min, ouverture morphologique (retire le bruit), puis suppression des composantes de moins de surface_min_tranchee.
  4. Zone d'intérêt. Dilatation du fond de marge_tranchee. Le modèle et le retour 3D ne regardent que cette zone.
  5. Retour à pleine résolution : plus proche voisin pour les masques, bilinéaire pour le sol ; hauteur_relative = hauteur − sol.
detecter_tranchee tranchee.py
def detecter_tranchee(r: Rasters, cfg: Config) -> Tranchee:
    H, W = r.forme
    f = max(1, int(round(cfg.grille_sol / r.pixel)))

    # 1. hauteur à basse résolution (médiane par bloc), trous comblés
    Hc, Wc = H // f, W // f
    blocs = r.hauteur[: Hc * f, : Wc * f].reshape(Hc, f, Wc, f).transpose(0, 2, 1, 3).reshape(Hc, Wc, -1)
    with np.errstate(all="ignore"):
        import warnings
        with warnings.catch_warnings():
            warnings.simplefilter("ignore", RuntimeWarning)
            hc = np.nanmedian(blocs, axis=2)
    vide = np.isnan(hc)
    if vide.all():
        raise ValueError("Raster de hauteur vide.")
    if vide.any():
        _, (il, ic) = ndi.distance_transform_edt(vide, return_indices=True)
        hc = hc[il, ic]

    # 2. sol = centile haut sur une grande fenêtre (insensible à la tranchée, plus étroite)
    taille = max(3, int(round(cfg.fenetre_sol / (f * r.pixel))) | 1)
    sol = ndi.percentile_filter(hc, cfg.centile_sol, size=taille, mode="nearest")
    sol = ndi.gaussian_filter(sol, taille / 4)

    # 3. tranchée = ce qui est nettement sous le sol
    fond = (sol - hc > cfg.profondeur_min) & ~vide
    fond = ndi.binary_opening(fond, iterations=1)
    etiq, n = ndi.label(fond)
    if n:
        aires = ndi.sum(fond, etiq, range(1, n + 1)) * (f * r.pixel) ** 2
        fond = np.isin(etiq, 1 + np.flatnonzero(aires >= cfg.surface_min_tranchee))

    # 4. marge autour de la tranchée
    n_marge = int(round(cfg.marge_tranchee / (f * r.pixel)))
    zone = ndi.binary_dilation(fond, iterations=max(1, n_marge)) if fond.any() else fond

    haut = lambda a, ordre: resize(a.astype(np.float32), (H, W), order=ordre, anti_aliasing=False)
    sol_plein = haut(sol, 1)
    return Tranchee(
        zone=haut(zone, 0) > 0.5,
        fond=haut(fond, 0) > 0.5,
        hauteur_relative=(r.hauteur - sol_plein).astype(np.float32),
    )

def tenseur_entree(r: Rasters, t: Tranchee) -> np.ndarray:
    """Entrée du modèle : (4, H, W) float32 = RVB normalisé + hauteur relative."""
    x = np.empty((4, *r.forme), np.float32)
    x[:3] = np.moveaxis(r.rvb, -1, 0) / 255.0
    h = np.nan_to_num(t.hauteur_relative, nan=0.0)
    x[3] = np.clip(h, -1.5, 1.5) / 1.5
    return x

06Étiquettes : GeoJSON → masque de classes

La vérité terrain est vectorielle ; le modèle apprend sur un masque raster aligné sur l'ortho, une valeur par pixel.

Entréeverite.geojson (LineString et Point 3D)
Sortiemasque (H, W) uint8 : 0 fond · 1 câble noir · 2 fourreau · 3 boîte · 4 coffret
Méthoderastérisation shapely buffer + rasterio rasterize, arbre KD scipy
Paramètrestampon_fourreau 3 cm · tampon_cable_noir 1,5 cm · rayon_boite 10 cm · rayon_coffret 18 cm · ecart_obstacle 10 cm · rouge_visible
  1. Chaque objet est élargi de son tampon, puis rastérisé. Les objets sont triés par classe : les ponctuels (3, 4) sont dessinés en dernier, par-dessus les câbles.
  2. Parties cachées. Un fourreau qui passe sous une plaque n'est pas visible sur l'ortho. Les lignes de vérité sont échantillonnées tous les 2 pixels avec leur Z ; pour chaque pixel étiqueté câble, on prend l'échantillon le plus proche (arbre KD) et, si la surface mesurée est plus de ecart_obstacle au-dessus, l'étiquette est retirée. Sinon le modèle apprendrait à voir un câble sur une plaque.
  3. Exception rouge. Un pixel de fourreau dont la couleur est rouge (TSV dans rouge_visible) reste étiqueté même s'il est au-dessus du point levé, par exemple un fourreau plaqué contre la paroi.

def rasteriser(objets, r: Rasters, origine, cfg: Config) -> np.ndarray:
    """Masque (H, W) uint8. Les ponctuels sont dessinés en dernier (au-dessus des câbles)."""
    tampons = {1: cfg.tampon_cable_noir, 2: cfg.tampon_fourreau, 3: cfg.rayon_boite, 4: cfg.rayon_coffret}
    formes = [(g.buffer(tampons[c]), c) for c, g, _ in sorted(objets, key=lambda o: o[0])]
    if not formes:
        return np.zeros(r.forme, np.uint8)
    masque = rasterize(formes, out_shape=r.forme, transform=r.affine_monde(origine), fill=0, dtype="uint8")
    _retirer_parties_cachees(masque, objets, r, origine, cfg)
    return masque

def _retirer_parties_cachees(masque, objets, r: Rasters, origine, cfg: Config) -> None:
    """Un câble levé qui passe sous un obstacle n'est pas visible sur l'ortho : là où la
    surface est nettement au-dessus du Z du câble, l'étiquette est retirée (sinon le modèle
    apprendrait à « voir » un câble sur l'obstacle). Nécessite un GeoJSON avec Z.
    Exception : un pixel de fourreau de couleur rouge (`rouge_visible`) est visible, par exemple contre une
    paroi au-dessus du point levé ; il reste étiqueté, sinon le modèle apprendrait ce rouge comme du fond."""
    lignes = [(c, g) for c, g, _ in objets if c in (1, 2) and g.geom_type == "LineString"]
    if not lignes:
        return
    if not all(g.has_z for _, g in lignes):
        print("  GeoJSON sans Z : les câbles passant sous un obstacle restent étiquetés.")
        return
    echantillons = []
    for _, g in lignes:
        c = np.array(g.coords, dtype=float) - origine
        s = np.concatenate([[0], np.cumsum(np.linalg.norm(np.diff(c[:, :2], axis=0), axis=1))])
        cible = np.arange(0, s[-1] + r.pixel, 2 * r.pixel)
        echantillons.append(np.column_stack([np.interp(cible, s, c[:, k]) for k in range(3)]))
    echantillons = np.vstack(echantillons)
    lig, col = np.nonzero((masque == 1) | (masque == 2))
    x, y = r.px_vers_xy(lig, col)
    _, plus_proche = cKDTree(echantillons[:, :2]).query(np.column_stack([x, y]))
    cache = r.hauteur[lig, col] - echantillons[plus_proche, 2] > cfg.ecart_obstacle
    cache &= ~((masque[lig, col] == 2) & est_rouge(r.rvb[lig, col], cfg))
    masque[lig[cache], col[cache]] = 0

08Le modèle : U-Net ResNet-18

Le seul composant appris de la chaîne. C'est une segmentation sémantique : pour chaque pixel de l'ortho, une probabilité pour chacune des 5 classes.

EncodeurResNet-18, poids ImageNet (torchvision) ; encodeur réglable (resnet34…)
Entrée / sortie[lot, 4, 384, 384] → logits [lot, 5, 384, 384]
Taille14 331 925 paramètres (encodeur 78 %, décodeur 22 %, tête 725)
smp.Unet(cfg.encodeur, encoder_weights=cfg.poids_encodeur or None, in_channels=4, classes=len(CLASSES))
  • Encodeur : ResNet-18, 4 étages de convolutions résiduelles qui divisent la résolution par 32. Il est pré-entraîné sur ImageNet (3 canaux) ; avec in_channels=4, smp adapte la première convolution en réutilisant les poids RVB pour le canal supplémentaire.
  • Décodeur : remonte la résolution par paliers et concatène à chaque palier les cartes de l'encodeur de même taille (les « connexions de saut ») : c'est ce qui garde la précision au pixel, indispensable pour un objet de 6 à 15 px de large.

  • Pas d'Ultralytics / YOLO (licence AGPL). Les poids ImageNet torchvision ont une licence à valider avant usage commercial.

La perte de distance (boundary loss)

L'entropie croisée et le Dice comptent des pixels justes ou faux, sans dire à quelle distance du tracé se trouve une erreur. Or on veut une précision centimétrique. Pour chaque classe d'objet, on précalcule la distance signée au tracé (distances_signees) : positive dehors, négative dedans, bornée à ±plafond_distance (20 cm). La perte multiplie la probabilité prédite par cette distance : prédire un fourreau à 15 cm du tracé coûte bien plus cher qu'à 1 cm.

Son poids suit un calendrier (poids_distance_courant) : nul pendant les premiers 30 % de l'entraînement (attente_distance), puis monte linéairement jusqu'à 3,0 sur les 30 % suivants (montee_distance). Appliquée dès le départ, elle pousse le modèle à ne plus rien prédire pour les classes rares. Elle est désactivée pour les boîtes et coffrets (distance_sur_ponctuels = False).

perte_distance modele.py
def perte_distance(logits, y, d, cfg: Config):
    """Boundary loss : somme(probabilité x distance signée normalisée) sur les classes
    d'objet, rapportée à la surface d'objet présente dans le lot. Vaut environ +1 si tout
    est prédit au plafond de distance ; négative quand les prédictions tombent dans les objets."""
    phi = d / cfg.plafond_distance
    if cfg.exposant_distance != 1.0:
        phi = phi.sign() * phi.abs() ** cfg.exposant_distance
    if not cfg.distance_sur_ponctuels:
        phi = phi.clone()
        phi[:, [c - 1 for c in PONCTUELS]] = 0      # boîtes et coffrets : CE + Dice seulement
    proba = logits.softmax(dim=1)[:, 1:]
    surface_objet = (y > 0).sum() + 1e-3 * y.numel()
    return (proba * phi).sum() / surface_objet
poids_distance_courant modele.py
def poids_distance_courant(pas_fait: int, total: int, cfg: Config) -> float:
    """0 pendant l'attente (le modèle apprend d'abord toutes les classes avec CE + Dice),
    puis montée linéaire jusqu'à `poids_distance`. Appliquée dès le départ, cette perte
    pousse le modèle à ne plus rien prédire pour les classes rares."""
    debut = cfg.attente_distance * total
    avancement = (pas_fait - debut) / max(1.0, cfg.montee_distance * total)
    return cfg.poids_distance * float(np.clip(avancement, 0.0, 1.0))
distances_signees modele.py
def distances_signees(masque: np.ndarray, pixel: float, plafond: float) -> np.ndarray:
    """(N_OBJETS, H, W) float16, en mètres : > 0 hors de l'objet, < 0 dedans, bornée à ± plafond.
    Une classe absente du chantier vaut +plafond partout."""
    d = np.full((N_OBJETS, *masque.shape), plafond, np.float16)
    for c in range(1, len(CLASSES)):
        objet = masque == c
        if objet.any():
            dehors = ndi.distance_transform_edt(~objet) * pixel
            dedans = ndi.distance_transform_edt(objet) * pixel
            d[c - 1] = np.clip(dehors - dedans, -plafond, plafond)
    return d

Validation et choix de l'epoch

À chaque epoch, valider parcourt les chantiers de validation en tuiles jointives et calcule l'IoU par classe (matrice de confusion) et un écart moyen au tracé symétrique : moyenne de la distance des pixels prédits au tracé (fausses détections) et de la distance du tracé à la prédiction (manques), bornée au plafond. Les poids de la meilleure epoch vont dans meilleur.pt. Les chantiers de --test ne sont mesurés qu'une fois, à la fin. Chaque epoch écrit une ligne dans historique.jsonl, que la page d'entraînement trace en direct.

def _lot_aleatoire(chantiers, cfg: Config, rng):
    xs, ys, ds = [], [], []
    t = cfg.tuile
    for _ in range(cfg.lot):
        ch = chantiers[rng.integers(len(chantiers))]
        sur_objet = len(ch.px_objet) and rng.random() < cfg.part_tuiles_objet
        source = ch.px_objet if sur_objet else ch.px_zone
        centre = source[rng.integers(len(source))] + rng.integers(-t // 3, t // 3 + 1, 2)
        # changement d'échelle : tuile plus grande ou plus petite, ramenée à t x t
        ts = int(round(t / rng.uniform(1 - cfg.echelle, 1 + cfg.echelle))) if cfg.echelle > 0 else t
        x, y, d = ch.tuile(centre, ts)
        if ts != t:
            x, y, d = _redimensionner(x, y, d, t)
        # augmentations géométriques (identiques pour l'entrée, les étiquettes et les distances)
        k = int(rng.integers(4))
        x, y, d = np.rot90(x, k, (1, 2)), np.rot90(y, k), np.rot90(d, k, (1, 2))
        if rng.random() < 0.5:
            x, y, d = x[:, :, ::-1], y[:, ::-1], d[:, :, ::-1]
        # augmentations radiométriques (RVB seulement) : luminosité, contraste, dominante
        x = x.copy()
        vide = ~x.any(axis=0)      # pixels sans point : restent à 0 comme à l'inférence
        _varier_fourreau(x, y, cfg, rng)
        gain = rng.uniform(0.75, 1.25) * rng.uniform(0.93, 1.07, (3, 1, 1))
        x[:3] = np.clip((x[:3] - 0.5) * rng.uniform(0.8, 1.2) + 0.5, 0, 1) * gain
        x[:3] = np.clip(x[:3] + rng.uniform(-0.08, 0.08), 0, 1)
        y, d = y.copy(), d.copy()
        # bruit capteur : couleurs, hauteur relative (canal normalisé par 1,5 m) et erreur sur le sol
        if cfg.bruit_rvb > 0:
            x[:3] = np.clip(x[:3] + rng.normal(0, cfg.bruit_rvb, x[:3].shape), 0, 1)
        x[3] += (rng.normal(0, cfg.bruit_hauteur, x[3].shape) + rng.uniform(-1, 1) * cfg.decalage_hauteur) / 1.5
        x[:, vide] = 0
        # trou : pixels vides comme dans un nuage incomplet ; l'objet n'y est pas visible, donc pas étiqueté
        if rng.random() < cfg.proba_trou:
            h, w = (rng.uniform(0.05, cfg.taille_trou, 2) * t).astype(int) + 1
            l0, c0 = rng.integers(0, t - h + 1), rng.integers(0, t - w + 1)
            x[:, l0:l0 + h, c0:c0 + w] = 0
            y[l0:l0 + h, c0:c0 + w] = 0
            d[:, l0:l0 + h, c0:c0 + w] = cfg.plafond_distance
        xs.append(x)
        ys.append(y)
        ds.append(d)
    return np.stack(xs).astype(np.float32), np.stack(ys), np.stack(ds)
valider modele.py
def valider(modele, chantiers, cfg: Config, periph):
    """Retourne (IoU par classe, écart moyen au tracé par classe d'objet, en mètres).

    L'écart est symétrique : moyenne de la distance des pixels prédits au tracé (fausses
    détections) et de la distance des pixels du tracé à la prédiction (manques). Il est
    borné au plafond, et mesuré tuile par tuile."""
    import torch
    n = len(CLASSES)
    plafond = cfg.plafond_distance
    confusion = np.zeros((n, n), np.int64)
    somme = np.zeros((2, N_OBJETS))      # [prédit -> tracé, tracé -> prédit]
    compte = np.zeros((2, N_OBJETS))
    modele.eval()
    with torch.no_grad():
        for ch in chantiers:
            for x, y, d in _tuiles_validation(ch, cfg.tuile):
                pred = modele(torch.from_numpy(x[None]).to(periph)).argmax(1)[0].cpu().numpy()
                confusion += np.bincount(y.ravel() * n + pred.ravel(), minlength=n * n).reshape(n, n)
                for c in range(1, n):
                    p, v = pred == c, y == c
                    if p.any():
                        somme[0, c - 1] += np.clip(d[c - 1][p], 0, None).sum()
                        compte[0, c - 1] += p.sum()
                    if v.any():
                        vers_pred = (np.minimum(ndi.distance_transform_edt(~p) * cfg.pixel, plafond)
                                     if p.any() else np.full(p.shape, plafond))
                        somme[1, c - 1] += vers_pred[v].sum()
                        compte[1, c - 1] += v.sum()
    inter = np.diag(confusion).astype(float)
    union = confusion.sum(0) + confusion.sum(1) - inter
    iou = np.where(union > 0, inter / np.maximum(union, 1), np.nan)
    # une classe présente dans le tracé mais jamais prédite compte au plafond
    aller = np.where(compte[0] > 0, somme[0] / np.maximum(compte[0], 1), plafond)
    retour = np.where(compte[1] > 0, somme[1] / np.maximum(compte[1], 1), np.nan)
    ecart = np.where(compte[1] > 0, (aller + retour) / 2, np.nan)
    return iou, ecart

def entrainer(fichiers_train, fichiers_val, sortie, cfg: Config, graine=0, reprendre=None, fichiers_test=()):
    """Entraîne, garde les meilleurs poids selon `cfg.critere` et exporte en ONNX."""
    import segmentation_models_pytorch as smp
    import torch

    sortie = Path(sortie)
    sortie.mkdir(parents=True, exist_ok=True)
    rng = np.random.default_rng(graine)
    torch.manual_seed(graine)
    periph = choisir_peripherique()
    print(f"Périphérique d'entraînement : {periph}")

    train = [Chantier(f, cfg) for f in fichiers_train]
    val = [Chantier(f, cfg) for f in fichiers_val]
    test = [Chantier(f, cfg) for f in fichiers_test]
    print(f"Chantiers : {len(train)} en entraînement, {len(val)} en validation, {len(test)} en test")
    print(f"Perte de distance : poids {cfg.poids_distance}, plafond {cfg.plafond_distance} m ; "
          f"critère de sélection : {cfg.critere}")

    modele = creer_modele(cfg)
    if reprendre:
        modele.load_state_dict(torch.load(reprendre, map_location="cpu"))
        print(f"Reprise depuis {reprendre}")
    modele = modele.to(periph)
    opt = torch.optim.AdamW(modele.parameters(), lr=cfg.taux_apprentissage, weight_decay=1e-4)
    total = cfg.epochs * cfg.iterations_par_epoch
    plan = torch.optim.lr_scheduler.OneCycleLR(opt, max_lr=cfg.taux_apprentissage, total_steps=total)
    ce = torch.nn.CrossEntropyLoss()
    dice = smp.losses.DiceLoss(mode="multiclass")

    meilleur, chemin_poids, pas_fait = None, sortie / "meilleur.pt", 0
    # historique lisible par l'atelier : une ligne JSON par epoch
    historique = open(sortie / "historique.jsonl", "w", encoding="utf-8")
    ecrire = lambda **e: (historique.write(json.dumps(e, ensure_ascii=False) + "\n"), historique.flush())
    nan_vers_none = lambda a: [None if np.isnan(v) else round(float(v), 5) for v in a]
    ecrire(type="debut", parametres=asdict(cfg), train=[c.nom for c in train], validation=[c.nom for c in val], test=[c.nom for c in test],
           reprendre=str(reprendre) if reprendre else None, peripherique=str(periph), t=time.time())
    for epoch in range(1, cfg.epochs + 1):
        debut_epoch = time.time()
        modele.train()
        cumul = cumul_dist = 0.0
        for _ in range(cfg.iterations_par_epoch):
            x, y, d = _lot_aleatoire(train, cfg, rng)
            x, y, d = (torch.from_numpy(a).to(periph) for a in (x, y, d))
            logits = modele(x)
            perte = ce(logits, y) + dice(logits, y)
            if cfg.poids_distance > 0:

                perte = perte + poids_distance_courant(pas_fait, total, cfg) * dist
                cumul_dist += dist.item()
            opt.zero_grad()
            perte.backward()
            opt.step()
            plan.step()
            pas_fait += 1
            cumul += perte.item()

        n_it = cfg.iterations_par_epoch
        if val:
            iou, ecart = valider(modele, val, cfg, periph)
            ecart_moyen = float(np.nanmean(ecart))
            iou_moyen = float(np.nanmean(iou[1:]))
            print(f"epoch {epoch:3d}  perte={cumul / n_it:.3f} (distance {cumul_dist / n_it:+.3f})  "

            retenu = meilleur is None or score > meilleur

            iou, ecart = np.full(len(CLASSES), np.nan), np.full(N_OBJETS, np.nan)
            ecart_moyen = iou_moyen = float("nan")
            print(f"epoch {epoch:3d}  perte={cumul / n_it:.3f} (distance {cumul_dist / n_it:+.3f})  (sans validation)")
            score, retenu = epoch, True
        if retenu:
            meilleur, resume = score, (epoch, iou_moyen, ecart_moyen)
            torch.save(modele.state_dict(), chemin_poids)
        ecrire(type="epoch", epoch=epoch, epochs=cfg.epochs, perte=cumul / n_it, distance=cumul_dist / n_it,

               ecart=dict(zip(CLASSES[1:], nan_vers_none(ecart))), retenu=retenu,

    modele.load_state_dict(torch.load(chemin_poids, map_location="cpu"))
    mesure_test = None
    if test:   # mesure unique, sur des chantiers qui n'ont servi ni à apprendre ni à choisir l'epoch
        iou, ecart = valider(modele, test, cfg, periph)
        mesure_test = {"iou_moyen": nan_vers_none([np.nanmean(iou[1:])])[0], "ecart_moyen": nan_vers_none([np.nanmean(ecart)])[0],
                       "iou": dict(zip(CLASSES[1:], nan_vers_none(iou[1:]))), "ecart": dict(zip(CLASSES[1:], nan_vers_none(ecart)))}
        print(f"Test ({', '.join(c.nom for c in test)}) : IoU {mesure_test['iou_moyen']}, "

Une ortho de chantier fait des milliers de pixels de côté. inference.predire la découpe en tuiles de 384 px qui se recouvrent de 64 px, et recolle les probabilités avec une pondération qui efface les coutures.

  2. Pour chaque lot : session.run, puis softmax sur les 5 logits.
  3. proba += p × hann, somme += hann ; à la fin proba /= somme.

def predire(entree: np.ndarray, zone: np.ndarray, chemin_onnx, cfg: Config, lot=4):
    """entree (4, H, W) -> (classes uint8 (H, W), confiance float32 (H, W))."""
    import json
    from pathlib import Path
    import onnxruntime as ort

    contrat = Path(chemin_onnx).with_suffix(".json")
    if contrat.exists():
        attendu = json.loads(contrat.read_text(encoding="utf-8"))
        ecarts = {k: (attendu[k], getattr(cfg, k)) for k in ("pixel", "fenetre_sol", "centile_sol")
                  if k in attendu and attendu[k] != getattr(cfg, k)}
        if ecarts:
            print(f"  attention : le modèle a été entraîné avec {ecarts} (valeur modèle, valeur actuelle) ; "
                  "l'ortho ne correspond plus à ce qu'il a appris.")
    session = ort.InferenceSession(str(chemin_onnx), providers=["CPUExecutionProvider"])
    t = session.get_inputs()[0].shape[2]
    t = t if isinstance(t, int) else cfg.tuile
    pas = t - cfg.recouvrement
    _, H, W = entree.shape

    # complète pour que la grille de tuiles couvre toute l'image
    Hp = max(t, int(np.ceil((H - t) / pas)) * pas + t) if H > t else t
    Wp = max(t, int(np.ceil((W - t) / pas)) * pas + t) if W > t else t
    x = np.zeros((4, Hp, Wp), np.float32)
    x[:, :H, :W] = entree
    z = np.zeros((Hp, Wp), bool)
    z[:H, :W] = zone

    # fenêtre de pondération : les bords de tuile comptent moins
    f = np.hanning(t + 2)[1:-1].astype(np.float32)
    poids = np.outer(f, f) + 1e-3
    proba = np.zeros((len(CLASSES), Hp, Wp), np.float32)
    somme = np.zeros((Hp, Wp), np.float32)

    coins = [(l, c) for l in range(0, Hp - t + 1, pas) for c in range(0, Wp - t + 1, pas)
             if z[l:l + t, c:c + t].any()]
    for i in range(0, len(coins), lot):
        groupe = coins[i:i + lot]
        logits = session.run(None, {"entree": np.stack([x[:, l:l + t, c:c + t] for l, c in groupe])})[0]
        e = np.exp(logits - logits.max(axis=1, keepdims=True))
        p = e / e.sum(axis=1, keepdims=True)
        for (l, c), pi in zip(groupe, p):
            proba[:, l:l + t, c:c + t] += pi * poids
            somme[l:l + t, c:c + t] += poids

    vu = somme > 0
    proba[:, vu] /= somme[vu]
    proba[0, ~vu] = 1.0
    classes = proba.argmax(0).astype(np.uint8)[:H, :W]
    confiance = proba.max(0)[:H, :W]
    classes[~zone] = 0
    return classes, confiance

1. Quels points ?

classer_points associe chaque point à son pixel et ne garde que la surface vue du dessus : z ≥ hauteur(pixel) − tolerance_surface. Un point sous une plaque, dans un pixel classé fourreau, n'appartient pas au fourreau.

2. Le squelette

Les petits morceaux de masque (moins de surface_min_px = 150 px) sont retirés. skimage.morphology.skeletonize réduit le masque à une ligne d'un pixel ; chemins_squelette le coupe aux embranchements (pixels à plus de 2 voisins) et ordonne chaque branche d'une extrémité à l'autre. Le rayon du câble est estimé par la médiane de la demi-largeur du masque le long du squelette (transformée de distance), borné entre 6 mm et 8 cm.

3. La crête, tous les 2 cm

  1. Le squelette est rééchantillonné tous les pas (2 cm).
  2. À chaque échantillon : points de surface à moins de max(rayon, 2 px) en plan (arbre KD) ; au moins 3 points.
  3. z_crête = 90e centile des Z ; XY = moyenne des points à moins de part_crete × rayon sous la crête.
  4. Les bouts (1,5 × rayon) sont rognés : le masque y est arrondi.
  5. Aberrants : une mesure à plus de 10 cm de la médiane locale sur 1 m (calculée en miroir) vient d'un objet posé sur le fourreau ; elle est remplacée par interpolation.
  6. Lissage : médiane 5 sur Z, Savitzky-Golay (fenêtre 9, ordre 2) sur XYZ, puis médiane et moyenne glissantes sur 1 m pour le Z : un fourreau ne fait pas de vaguelettes de quelques centimètres.
  7. Avec convention = "axe", on retire le rayon au Z pour donner l'axe du câble.

4. Boîtes et coffrets

Ouverture morphologique (2 itérations), composantes connexes, puis pour chaque objet de plus de 150 px et 10 points : XY moyen, Z du dessus = 98e centile, z_min = 2e centile, emprise en plan.

def extraire(classes: np.ndarray, confiance: np.ndarray, r: Rasters, nuage: Nuage, cfg: Config):
    """Retourne (tronçons observés, ponctuels)."""
    lig, col, surface, classe_pt = classer_points(classes, r, nuage, cfg)

    troncons: list[Troncon] = []
    for c in LINEAIRES:
        masque = _sans_petits_objets(classes == c, cfg.surface_min_px)
        idx = np.flatnonzero(classe_pt == c)
        if not masque.any() or len(idx) == 0:
            continue
        pts_c = nuage.xyz[idx]
        arbre = cKDTree(pts_c[:, :2])
        demi_largeur = ndi.distance_transform_edt(masque) * r.pixel

        for chemin in chemins_squelette(masque):
            l, k = chemin[:, 0], chemin[:, 1]
            rayon = float(np.clip(np.median(demi_largeur[l, k]), cfg.rayon_min, cfg.rayon_max))
            xy = _reechantillonner(np.column_stack(r.px_vers_xy(l, k)), cfg.pas)
            mesures = []
            for p, voisins in zip(xy, arbre.query_ball_point(xy, max(rayon, 2 * r.pixel))):
                if len(voisins) < 3:
                    continue
                v = pts_c[voisins]
                z_crete = np.percentile(v[:, 2], 90)
                haut = v[v[:, 2] >= z_crete - cfg.part_crete * rayon]
                mesures.append([*haut[:, :2].mean(axis=0), z_crete])
            # les bouts du squelette sont peu fiables (masque arrondi) : on les rogne
            rogne = int(np.ceil(1.5 * rayon / cfg.pas))
            if len(mesures) > 2 * rogne + 4:
                mesures = mesures[rogne:-rogne]
            if len(mesures) < 4:
                continue
            mesures = np.array(mesures)
            mesures[:, 2] = sans_aberrants_z(mesures[:, 2], cfg)
            pts = _lisser(mesures, cfg.lissage)
            pts[:, 2] = lisser_z(pts[:, 2], cfg)
            if cfg.convention == "axe":
                pts[:, 2] -= rayon
            t = Troncon(c, pts, "observe", float(confiance[l, k].mean()), rayon)
            if t.longueur >= cfg.longueur_min:
                troncons.append(t)

    ponctuels: list[Ponctuel] = []
    for c in PONCTUELS:
        masque = ndi.binary_opening(classes == c, structure=HUIT, iterations=2)
        etiq, n = ndi.label(masque)
        etiq_pt = np.where(surface, etiq[lig, col], 0)
        for k in range(1, n + 1):
            if (etiq == k).sum() < cfg.surface_min_px:
                continue
            v = nuage.xyz[etiq_pt == k]
            if len(v) < 10:
                continue
            z_haut, z_bas = np.percentile(v[:, 2], [98, 2])
            ponctuels.append(Ponctuel(
                c, np.array([*v[:, :2].mean(axis=0), z_haut]), float(z_bas),
                (*v[:, :2].min(axis=0), *v[:, :2].max(axis=0)),
                float(confiance[etiq == k].mean()),
            ))
    return troncons, ponctuels

def chemins_squelette(masque: np.ndarray):
    """Découpe le squelette aux embranchements et renvoie des chemins de pixels ordonnés."""
    sk = skeletonize(masque)
    nb = ndi.convolve(sk.astype(np.uint8), HUIT.astype(np.uint8), mode="constant") - 1
    noeuds = sk & (nb > 2)
    branches = sk & ~ndi.binary_dilation(noeuds, structure=HUIT)
    etiq, _ = ndi.label(branches, structure=HUIT)
    for k, tranche in enumerate(ndi.find_objects(etiq), 1):
        coords = np.argwhere(etiq[tranche] == k)
        if len(coords) >= 3:
            yield _ordonner(coords) + [tranche[0].start, tranche[1].start]

def classer_points(classes: np.ndarray, r: Rasters, nuage: Nuage, cfg: Config):
    """Pixel de chaque point, masque des points de surface et classe de chaque point (0 si caché)."""
    H, W = r.forme
    lig, col = r.xy_vers_px(nuage.xyz[:, 0], nuage.xyz[:, 1])
    dedans = (lig >= 0) & (lig < H) & (col >= 0) & (col < W)
    lig, col = lig.clip(0, H - 1), col.clip(0, W - 1)
    # on ne garde que la surface vue du dessus (pas les points cachés sous un objet)
    surface = dedans & (nuage.xyz[:, 2] >= r.hauteur[lig, col] - cfg.tolerance_surface)
    return lig, col, surface, np.where(surface, classes[lig, col], 0)

def sans_aberrants_z(z: np.ndarray, cfg: Config) -> np.ndarray:
    """Mesures de crête prises sur un objet au-dessus du câble (planche, plaque) : écartées si elles
    s'éloignent de plus de `ecart_z_aberrant` de la médiane sur `lissage_z`, puis interpolées.
    Médiane en miroir : en bout de tronçon, recopier le premier point (souvent l'aberrant) la fausserait."""
    n = min(len(z), int(round(cfg.lissage_z / cfg.pas))) | 1
    if cfg.ecart_z_aberrant <= 0 or n < 3:
        return z
    garde = np.abs(z - ndi.median_filter(z, size=n, mode="reflect")) <= cfg.ecart_z_aberrant
    if garde.all() or not garde.any():
        return z
    i = np.arange(len(z))
    return np.interp(i, i[garde], z[garde])

def lisser_z(z: np.ndarray, cfg: Config) -> np.ndarray:
    """Profil en long : médiane glissante (écarte les points de paroi ou de terre) puis moyenne
    glissante sur `lissage_z` mètres. Un fourreau ne fait pas de vagues de quelques centimètres."""
    n = min(len(z), int(round(cfg.lissage_z / cfg.pas))) | 1
    if cfg.lissage_z <= 0 or n < 3:
        return z
    return ndi.uniform_filter1d(ndi.median_filter(z, size=n, mode="nearest"), n, mode="nearest")

def _lisser(pts: np.ndarray, fenetre: int) -> np.ndarray:
    n = len(pts)
    pts = pts.copy()
    if n >= 5:
        pts[:, 2] = ndi.median_filter(pts[:, 2], size=5, mode="nearest")   # points aberrants en Z
    f = min(fenetre, n if n % 2 else n - 1)
    if f >= 5:
        pts = savgol_filter(pts, f, 2, axis=0, mode="interp")
    return pts

  3. Passe 2, zones masquées : extrémités à moins de trou_max. Au-delà de trou_libre, chaque bout doit « regarder » l'autre à moins de 35° et la pente rester sous 0,5. Coût = d / trou_max + (a1 + a2) / (2 · angle_max).
  4. Les candidats sont pris par coût croissant, chaque extrémité une seule fois (glouton), puis chaînés : chaque chaîne reçoit un id_cable.
  5. Entre deux tronçons d'une chaîne : pont de Hermite cubique, tangentes multipliées par la longueur du trou, échantillonné tous les 2 cm, origine = deduit, confiance = 0.

(2s³ − 3s² + 1)·p0 + (s³ − 2s² + s)·m0 + (−2s³ + 3s²)·p1 + (s³ − s²)·m1

def raccorder(troncons: list[Troncon], cfg: Config) -> list[Troncon]:
    """Retourne les tronçons observés fusionnés + les tronçons déduits, avec un id_cable commun."""
    if not troncons:
        return []
    troncons = sans_eperons(troncons, cfg)
    oriente = lambda t, inverse: t.pts[::-1] if inverse else t.pts

    # passe 1 : fusion des trous courts
    fusionnes = []
    for chaine in _chainer(len(troncons), _apparier(troncons, cfg.trou_observe, cfg, False)):
        membres = [troncons[i] for i, _ in chaine]
        pts = np.vstack([oriente(troncons[i], inv) for i, inv in chaine])
        longueurs = [m.longueur for m in membres]
        fusionnes.append(Troncon(
            membres[0].classe, pts, "observe",
            float(np.average([m.confiance for m in membres], weights=longueurs)),
            float(np.average([m.rayon for m in membres], weights=longueurs)),
        ))
    fusionnes = [t for t in fusionnes if t.longueur >= cfg.longueur_min]

    # passe 2 : ponts « déduits » à travers les zones masquées
    portee = int(round(cfg.portee_tangente / cfg.pas))
    resultat = []
    chaines = _chainer(len(fusionnes), _apparier(fusionnes, cfg.trou_max, cfg, True))
    for id_cable, chaine in enumerate(chaines):
        precedent = None
        for i, inverse in chaine:
            t = fusionnes[i]
            pts = oriente(t, inverse)
            if precedent is not None:
                t0 = _tangente_sortante(precedent, 1, portee)
                t1 = -_tangente_sortante(pts, 0, portee)
                resultat.append(Troncon(t.classe, _pont(precedent[-1], t0, pts[0], t1, cfg.pas),
                                        "deduit", 0.0, t.rayon, id_cable))
            resultat.append(Troncon(t.classe, pts, "observe", t.confiance, t.rayon, id_cable))
            precedent = pts
    return resultat

def _apparier(troncons, d_max, cfg: Config, avec_angles: bool):
    """Liste de paires ((i, bout_i), (j, bout_j)) retenues, sans réutiliser une extrémité."""
    portee = int(round(cfg.portee_tangente / cfg.pas))
    bouts = [(i, b, t.pts[0 if b == 0 else -1], _tangente_sortante(t.pts, b, portee))
             for i, t in enumerate(troncons) for b in (0, 1)]
    candidats = []
    for a in range(len(bouts)):
        ia, ba, pa, ta = bouts[a]
        for b in range(a + 1, len(bouts)):
            ib, bb, pb, tb = bouts[b]
            if ia == ib or troncons[ia].classe != troncons[ib].classe:
                continue
            v = pb - pa
            d = float(np.linalg.norm(v))
            if d > d_max:
                continue
            cout = d / d_max
            if avec_angles and d > 1e-6:
                u = v / d
                a1 = np.degrees(np.arccos(np.clip(ta @ u, -1, 1)))     # A regarde-t-il vers B ?
                a2 = np.degrees(np.arccos(np.clip(tb @ -u, -1, 1)))    # B regarde-t-il vers A ?
                pente = abs(v[2]) / max(np.linalg.norm(v[:2]), 1e-6)
                # trou court : la proximité suffit (coude, remontée) ; l'angle ne sert qu'à classer
                if d > cfg.trou_libre and (a1 > cfg.angle_max or a2 > cfg.angle_max or pente > cfg.pente_max):
                    continue
                cout += (a1 + a2) / (2 * cfg.angle_max)
            candidats.append((cout, (ia, ba), (ib, bb)))
    pris, paires = set(), []
    for _, ea, eb in sorted(candidats, key=lambda c: c[0]):
        if ea not in pris and eb not in pris:
            pris.update((ea, eb))
            paires.append((ea, eb))
    return paires

def _pont(p0, t0, p1, t1_entrant, pas) -> np.ndarray:
    """Courbe de Hermite entre deux extrémités, tangente aux deux tronçons."""
    d = np.linalg.norm(p1 - p0)
    n = max(2, int(round(d / pas)))
    s = np.linspace(0, 1, n + 1)[:, None]
    m0, m1 = t0 * d, t1_entrant * d
    return ((2 * s**3 - 3 * s**2 + 1) * p0 + (s**3 - 2 * s**2 + s) * m0
            + (-2 * s**3 + 3 * s**2) * p1 + (s**3 - s**2) * m1)

def sans_eperons(troncons: list[Troncon], cfg: Config) -> list[Troncon]:
    """Retire les petits tronçons qui doublent un tronçon plus long de même classe (branches
    du squelette) : sinon ils prennent les extrémités et bloquent le raccordement."""
    import shapely
    gardes = []
    for t in sorted(troncons, key=lambda t: -t.longueur):
        points = shapely.points(t.pts[:, :2])
        if t.longueur < cfg.longueur_eperon and any(
                g.classe == t.classe
                and shapely.distance(shapely.linestrings(g.pts[:, :2]), points).max() < cfg.ecart_eperon
                for g in gardes):
            continue
        gardes.append(t)
    return gardes

14Raccord aux boîtes et coffrets

Au récolement, un fourreau se termine à l'entrée d'un ouvrage. Le modèle, lui, s'arrête souvent quelques dizaines de centimètres avant. raccorder_ouvrages prolonge les bouts libres.

  1. Bouts libres (bouts_libres) : extrémités qui ne touchent, à 6 cm près, aucune autre extrémité du même câble.
  2. Ouvrage le plus proche en plan ; prolongement si la distance est comprise entre trou_observe et distance_ouvrage_max (2 m).
  3. Point d'arrivée : z_min + hauteur_entree_ouvrage (40 cm, médiane du récolement), sans dépasser le dessus de l'objet.
  4. Courbe de Hermite partant dans la direction du câble ; même classe et même id_cable que le câble, origine = deduit.

def raccorder_ouvrages(troncons: list[Troncon], ponctuels: list[Ponctuel], cfg: Config) -> list[Troncon]:
    """Prolonge chaque bout libre jusqu'à la boîte ou au coffret le plus proche (à moins de distance_ouvrage_max
    en plan) : courbe 3D partant dans la direction du câble, jusqu'à l'entrée de l'objet (z_min + hauteur_entree_ouvrage,
    sans dépasser son dessus), comme le point levé au récolement.
    Le prolongement garde la classe et l'id_cable du câble (continuité du fourreau) et est « deduit »."""
    if not ponctuels:
        return troncons
    portee = int(round(cfg.portee_tangente / cfg.pas))
    objets = np.array([[*p.xyz[:2], min(p.z_min + cfg.hauteur_entree_ouvrage, p.xyz[2])] for p in ponctuels])
    ajouts = []
    for t, b in bouts_libres(troncons, cfg.trou_observe):
        pts = t.pts if b == -1 else t.pts[::-1]
        bout = pts[-1]
        d = np.linalg.norm(objets[:, :2] - bout[:2], axis=1)
        k = int(d.argmin())
        if not cfg.trou_observe < d[k] <= cfg.distance_ouvrage_max:
            continue
        arrivee = (objets[k] - bout) / np.linalg.norm(objets[k] - bout)
        chemin = _pont(bout, _tangente_sortante(pts, 1, portee), objets[k], arrivee, cfg.pas)
        ajouts.append(Troncon(t.classe, chemin, "deduit", 0.0, t.rayon, t.id_cable))
    return troncons + ajouts

def evaluer(chemin_prediction, chemin_verite, cfg: Config) -> dict:
    """Écarts en mètres. La comparaison est 3D si la vérité terrain porte un Z, sinon 2D."""
    pred_l, pred_p = _charger(chemin_prediction, "classe", cfg.pas_eval)
    vrai_l, vrai_p = _charger(chemin_verite, cfg.champ_classe, cfg.pas_eval)
    tol, bilan = cfg.tolerance_eval, {}

    for classe in CLASSES[1:3]:
        if classe not in vrai_l:
            continue
        v = np.vstack([p for p, _ in vrai_l[classe]])
        dim = 3 if v.shape[1] >= 3 else 2
        res = {"dimension": f"{dim}D", "longueur_verite_m": round(len(v) * cfg.pas_eval, 2)}
        if classe in pred_l:
            arbre_v = cKDTree(v[:, :dim])
            tout = np.vstack([p for p, _ in pred_l[classe]])
            res["part_verite_retrouvee"] = round(float(
                (cKDTree(tout[:, :dim]).query(v[:, :dim])[0] <= tol).mean()), 3)
            for origine in ("observe", "deduit"):
                sel = [p for p, pr in pred_l[classe] if pr.get("origine") == origine]
                if sel:
                    d = arbre_v.query(np.vstack(sel)[:, :dim])[0]
                    res[origine] = {
                        "longueur_m": round(len(d) * cfg.pas_eval, 2),
                        "ecart_median_m": round(float(np.median(d)), 4),
                        "ecart_p95_m": round(float(np.percentile(d, 95)), 4),
                    }
        else:
            res["part_verite_retrouvee"] = 0.0
        bilan[classe] = res

    for classe in CLASSES[3:]:
        v, p = vrai_p.get(classe, []), pred_p.get(classe, [])
        if not v and not p:
            continue
        trouves, ecarts, libres = 0, [], list(range(len(p)))
        for pv in v:
            if not libres:
                break
            d = [np.linalg.norm(p[j][:2] - pv[:2]) for j in libres]
            j = int(np.argmin(d))
            if d[j] <= max(tol, cfg.tolerance_ponctuel):
                trouves += 1
                ecarts.append(d[j])
                libres.pop(j)
        bilan[classe] = {
            "verite": len(v), "predits": len(p), "trouves": trouves,
            "rappel": round(trouves / len(v), 3) if v else None,
            "precision": round(trouves / len(p), 3) if p else None,
            "ecart_plan_median_m": round(float(np.median(ecarts)), 4) if ecarts else None,
        }
    return bilan

  1. Requête à l'API Enedis (jeux reseau-souterrain-bt et reseau-bt) autour du chantier : within_distance sur un rayon de demi-diagonale + marge_reseau (30 m), par pages de 100.
  2. Reprojection WGS84 → CRS du nuage (pyproj), découpe à l'emprise ; cache opendata_bt.geojson.
  3. Mise en 3D : souterrain au Z médian des câbles observés, aérien au sol + hauteur_aerien (8 m).
  4. Un raccord probable par câble : du bout libre le plus proche vers la ligne la plus proche, à moins de distance_raccord_max (15 m) ; vers l'aérien, un poteau est ajouté.
  5. Hors ligne ou API en panne : simple avertissement, le résultat reste valable.

def raccorder_reseau(reseau: dict, troncons: list[Troncon], nuage: Nuage, cfg: Config) -> dict:
    """Réseau existant en 3D + un raccord probable par câble (bout libre le plus proche, à moins de
    distance_raccord_max en plan) ; FeatureCollection 3D en coordonnées d'origine."""
    sol = float(np.median(nuage.xyz[:, 2]))
    obs = [t.pts[:, 2] for t in troncons if t.origine == "observe"]
    z_sout = float(np.median(np.concatenate(obs))) if obs else sol
    z_classe = {"bt_souterrain": z_sout, "bt_aerien": sol + cfg.hauteur_aerien}
    o = nuage.origine
    lignes = [(f["properties"]["classe"], LineString(np.asarray(f["geometry"]["coordinates"])[:, :2] - o[:2]))
              for f in reseau["features"]]

    sortie = []
    ajouter = lambda classe, pts, **p: sortie.append({
        "type": "Feature", "properties": {"classe": classe, "origine": "opendata", **p},
        "geometry": {"type": "LineString", "coordinates": (np.asarray(pts) + o).round(4).tolist()}})
    for classe, l in lignes:
        xy = np.array(l.coords)
        ajouter(classe, np.column_stack([xy, np.full(len(xy), z_classe[classe])]), source=SOURCE)

    par_cable = {}
    for t, i in bouts_libres(troncons, cfg.trou_observe):
        par_cable.setdefault(t.id_cable, []).append(t.pts[i])
    for cable, bouts in par_cable.items():
        candidats = [(l.distance(Point(b[:2])), classe, l, b) for classe, l in lignes for b in bouts]
        if not candidats:
            break
        d, classe, l, b = min(candidats, key=lambda c: c[0])
        if d > cfg.distance_raccord_max:
            continue
        cible = np.array(nearest_points(l, Point(b[:2]))[0].coords[0])
        pts = [b, [*cible, b[2]]]
        if classe == "bt_aerien":
            pts.append([*cible, z_classe[classe]])
            ajouter("poteau_ajoute", [[*cible, sol], [*cible, z_classe[classe]]], id_cable=cable)
        ajouter("raccord_probable", pts, type_reseau=classe, id_cable=cable, distance_m=round(d, 2))
    fc = {"type": "FeatureCollection", "features": sortie}
    if nuage.crs:
        fc["crs"] = {"type": "name", "properties": {"name": nuage.crs}}
    return fc

19Limites connues

  • Pas d'exemple de câble noir nu dans les 11 chantiers : la classe existe mais n'est ni apprise ni mesurée.
  • Câbles superposés : un seul Z par pixel vu du dessus ; deux fourreaux empilés donnent un seul tracé.
  • Câble contre une paroi verticale : presque invisible sur une ortho.
  • Appariement glouton : suffisant sur les chantiers actuels ; une affectation globale (hongrois) serait plus sûre aux croisements.
  • Précision plafonnée par le géoréférencement du nuage et par le décalage éventuel entre récolement et nuage.
